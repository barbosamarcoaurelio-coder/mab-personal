# Publicação simplificada

## GitHub Pages

1. Crie um repositório vazio no GitHub.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Confirme que a branch principal se chama `main`.
4. No repositório, abra **Settings > Pages**.
5. Em **Build and deployment > Source**, escolha **GitHub Actions**.
6. Abra **Actions** e execute o fluxo **Publicar PWA no GitHub Pages**, se ele não iniciar automaticamente.
7. Ao concluir, a página de execução exibirá o endereço HTTPS publicado.

## Instalação no iPhone

1. Abra o endereço HTTPS no Safari.
2. Toque em **Compartilhar**.
3. Toque em **Adicionar à Tela de Início**.
4. Mantenha **Abrir como App da Web** ativado.
5. Toque em **Adicionar**.

A instalação na Tela de Início exige uma ação do próprio usuário no iPhone.
