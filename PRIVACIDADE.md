# Política de Privacidade

O Controle de Treinos MAB Personal armazena os dados localmente no navegador, usando IndexedDB. Esta versão não envia dados para servidor, não utiliza publicidade e não inclui telemetria.

O usuário é responsável por exportar backups periódicos. A limpeza dos dados do navegador ou a troca do aparelho pode remover o banco local.

O aplicativo não substitui orientação médica, nutricional ou profissional.
